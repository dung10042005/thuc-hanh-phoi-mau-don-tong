# Thực hành phối màu đơn tông

## Cách chạy
1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt hoặc mở thư mục trong VS Code.
3. Trong VS Code, có thể cài Live Server rồi chọn **Open with Live Server** trên `index.html`.

## Bảng màu chính
- Bậc 1: `#00ADEE`
- Bậc 2: `#00B2EF`
- Bậc 4: `#00BFF2`
- Bậc 7: `#8DD7F7`
- Bậc 9: `#C6E9FA`

Màu nền hero dùng bậc 4, nền nội dung thẻ khóa học dùng bậc 7, footer dùng nền sáng trung tính và các điểm nổi bật dùng bậc 1/2. Màu chữ chính giữ màu đen để dễ đọc.

## Phương án màu thứ hai
Trong `style.css`, cuối file có khối `:root` xanh lá đang được chú thích. Bỏ dấu chú thích `/*` và `*/` bao quanh khối để thử bảng màu xanh lá; nhớ chú thích khối xanh dương ở đầu file nếu muốn thay hoàn toàn.
